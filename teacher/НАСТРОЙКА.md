# Easy Python PRO: как подключить журнал (≈5 минут, один раз)

PRO-версия хранит учителей, классы и прогресс учеников в **новой** Google-таблице.
Таблицу обычной версии сайта (pystart) не трогайте — это отдельные журналы.

## 1. Создайте таблицу
1. Откройте <https://sheets.new>.
2. Назовите её, например: **Easy Python PRO — журнал**.

## 2. Вставьте скрипт
1. В таблице: **Расширения → Apps Script**.
2. Удалите всё в файле `Code.gs` и вставьте содержимое файла [`Code.gs`](Code.gs) из этой папки.
3. В строке `const ADMIN_KEY = "поменяйте-меня";` впишите свой **пароль администратора** —
   в прямых кавычках `"…"`, как в примере. Пока стоит «поменяйте-меня», вход администратора не работает.
4. 💾 **Сохранить**.

## 3. Опубликуйте как веб-приложение
1. **Начать развертывание → Новое развертывание** → тип **Веб-приложение**.
2. **Запуск от имени:** Я. **У кого есть доступ:** **Все**.
3. **Начать развертывание** → **Предоставить доступ** → свой аккаунт →
   «Дополнительные настройки» → «Перейти на страницу проекта (небезопасно)» → **Разрешить**.
4. Скопируйте **URL веб-приложения** (оканчивается на `/exec`) и пришлите Claude — он впишет его в `config.js`.

## Как этим пользоваться

**Учитель**
1. Открывает сайт → внизу главной «👩‍🏫 Для учителя» → **Регистрация** (ФИО, школа, логин, пароль).
2. В разделе **«Мои классы»** создаёт класс — получает **код** (например, `K7X2QP`) и **ссылку-приглашение**.
3. Отправляет ссылку ученикам в чат класса или диктует код.
4. В **«Журнале»** видит только своих учеников: прогресс, задачи с кодом каждой попытки, ответы на тесты.

**Ученик**
- Открывает ссылку-приглашение (код подставится сам) и на вкладке **«Регистрация»** вводит имя, класс, PIN.
- С другого устройства — вкладка **«Вход»** (те же имя, класс, PIN). Забыл PIN — учитель сбросит его на странице ученика.
- Или вводит код в поле «Код класса» при первом входе, или позже в меню: **«Ввести код класса»**.
- Перед вступлением видит, к какому классу и учителю попадёт.

**Администратор (вы)**
- «Вход администратора» на странице учителя, пароль — ADMIN_KEY.
- Видит **всех** учеников и все классы, раздел **«Учителя»**: сколько у кого классов и учеников,
  **сброс пароля** (сайт покажет новый временный пароль — передайте учителю) и **отключение** аккаунта.

## Полезно знать
- Пароли учителей хранятся в таблице только в виде хэша с солью — их не видно даже владельцу таблицы.
- Вход действует 30 дней, потом сайт попросит войти снова. Кнопка «Выйти» завершает вход на этом устройстве.
- Сменить свой пароль учитель может в разделе **«Аккаунт»**.
- «Закрыть класс» запрещает вступать по коду; уже вступившие ученики и их история остаются.
- Ученик может перейти в другой класс, введя новый код; его прогресс сохраняется.
- Ученик может заниматься с нескольких устройств одновременно (вкладка «Вход»): решённое на любом из них объединяется, ничего не теряется.
- **Изменили скрипт?** Развертывание → Управление развертываниями → ✏️ → Версия: **Новая версия** → Развернуть.
- Данные всех учителей и учеников хранятся в вашей таблице (вы — её владелец). Для школы это нормально;
  если сайтом будут пользоваться посторонние учителя, предупредите их об этом.

(инструкция — в начале файла). Сайтом он не подключается.
